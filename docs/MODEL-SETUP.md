# Recommended models and source access

Checked 2 October 2026. These are suggested starting points based on the providers' descriptions of their models. Posek has not compared these named models head to head. The recorded development pilots did not expose exact model identifiers, so their scores cannot establish a model ranking or minimum supported version.

## ChatGPT

Choose **Astra** when it is available in your model picker. For a difficult shailah or a comparison of several poskim, increase reasoning effort if your interface offers it. OpenAI describes Astra as its strongest option for demanding analysis. A reasoning model with source access is an alternative when Astra is unavailable. Plan, workspace, and client affect the choices shown. [Model selection](https://learn.chatgpt.com/docs/model-selection), [availability and controls](https://learn.chatgpt.com/docs/models).

## Claude

Start with **Opus 5.5 at High effort** for difficult shailos. **Sonnet 5.5** is a reasonable starting point for shorter Torah drafts and revisions. This is a task-fit recommendation from the provider's guidance, not a halachic reliability finding. More effort takes longer and uses more of your allowance. [Current models](https://platform.claude.com/docs/en/models/overview), [model and effort settings](https://support.claude.com/en/articles/8664678-change-the-model-effort-and-thinking-settings).

Allow web search and explicitly ask Claude to open the relevant primary texts. Some interfaces have a Web search switch; the newer interface searches automatically when useful. Workspace administrators can control access. [Claude web search](https://support.claude.com/en/articles/10684626-enable-and-use-web-search).

## Use the phone starter

1. Choose the hashkafah, task, audience, and depth on the phone page. Add the facts that matter to the shailah, including your minhag when relevant.
2. Copy the starter into a fresh chat. Select the model in that app; copying a prompt does not change the model or enable its tools.
3. Ask it to open the primary sources. If a text is inaccessible, supply the passage or retain the unresolved gap. A remembered citation is not inspected evidence.
4. Check the quoted wording, its speaker, and whether it supports the conclusion. For a practical shailah, confirmation with your local rav is recommended. Bring the mareh mekomos.

The phone starter is shorter than the installed skill. No named subscription or model guarantees a correct answer. A newer model can still invent a citation or misapply a source; source verification remains part of the task. Urgent danger requires immediate help, and personal-status or institutional decisions require the appropriate qualified authority.

The complete bundle for Claude Code and Codex includes the longer source method, references, and retrieval helper. Its instructions handle unavailable retrieval explicitly; they do not treat a model name as evidence that a passage was checked.
